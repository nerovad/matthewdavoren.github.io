Paperboy
Paperboy is an enterprise workflow platform in Rails 8 featuring configurable multi-step routing, status lifecycle management, and event-driven notifications via a Sidekiq/Redis job processing pipeline to digitize hundreds of paper-based forms.

Cinezoo
Cinezoo is a live, channel-based streaming and film festival platform that blends internet TV with creative competition, letting users create channels, stream content, run tournaments, and interact through chat and voting in a retro-styled interface. It’s built with React + TypeScript (Vite) on the frontend and a Node.js + Express + Socket.IO backend, backed by PostgreSQL, with HLS-based streaming infrastructure for live and on-demand video.

Cartoon Backgrounds
Built a generative AI pipeline that fine-tunes Stable Diffusion v1.5 using LoRA (Low-Rank Adaptation) to produce 90s cartoon-style background images from text prompts. The project includes a custom training loop with data augmentation, mixed-precision training, and gradient accumulation, as well as a CLI-based inference script for batch image generation. Tech stack: Python, PyTorch, Hugging Face Diffusers/PEFT/Transformers, Stable Diffusion v1.5, LoRA, CUDA, and Docker.
